# v1.3 — адаптивная графика и расширяемые контракты

## Что изменено
- Геометрия окна FLTK теперь вычисляется относительно текущих размеров: шапка, художественная обложка, список заказов, карта, история, журнал и кнопки адаптируются к ширине и высоте. Минимум окна 960×690.
- Изображение обложки масштабируется с сохранением пропорций и центральным кадрированием вместо растяжения на панель.
- Карту можно увеличивать вместе с окном: положения точек, линии и декоративная сетка рассчитываются от текущих `w()` и `h()`; клик использует те же координаты, что и отрисовка.
- Геометрию вынесли в `src/gui/ResponsiveLayout.h`, пригодный для модульных тестов без FLTK.
- При загрузке старого героя `PgGameRepository::loadProgress()` создаёт отсутствующие записи `hero_contracts` для новых контрактов без изменения существующего прогресса.
- Мирный ритуал больше не привязан к `id=2`: он зависит от слабости чудовища `sigil`.
- Добавлен `sql/add_contract_example.sql`: четвёртый контракт в уже существующей Топкой низине. Скрипт **не выполняется автоматически**.
- Добавлен `docs/ADDING_CONTRACTS.md` с инструкцией по расширению мира.
- Добавлено семь тестов: несколько контрактов в одной локации, расширение сохранения, ритуал на новом ID, дублирование ID, три размера GUI. Итого **46 модульных тестов**.

## Безопасное обновление
- Старая схема БД v1.2 подходит без изменений: **новая миграция PostgreSQL не нужна**.
- Разархивируйте патч поверх исходников v1.2, пересоберите `cmake --build build -j$(nproc)` и перезапустите приложение.
- Чтобы добавить четвёртый заказ в PostgreSQL, **по желанию** выполните `psql "$BORDERLAND_DB" -v ON_ERROR_STOP=1 -f sql/add_contract_example.sql`.
- Для игры в `--demo` новый SQL-файл не работает: он предназначен для PostgreSQL.

## Проверки
- Ядро и CLI: CMake + CTest, 46/46 пройдено.
- Геометрия трёх размеров: проверена на рассчитанных координатах без GUI.
- Полноценная компиляция GUI с FLTK и интеграция с PostgreSQL в этой среде недоступны из-за отсутствия соответствующих библиотек. Проверяются на WSL с `libfltk1.3-dev` и `libpqxx-dev`.
