# 🐾 Лапки любви — Пушистый сюрприз для мамы

Интерактивная открытка на русском языке. Главный герой — миттельшнауцер окраса «перец с солью». Семь последовательных экранов, пять поглаживаний, пять цветов, три письма, подарок, финал и повторное прохождение.

## Запуск на Windows (PowerShell)

Распакуйте архив, откройте терминал в папке `PawsOfLove` и выполните:

```powershell
python -m http.server 8000
```

Откройте http://localhost:8000/ в браузере. Если `python` не найден, используйте `py -m http.server 8000`. Открывать index.html двойным щелчком не рекомендуется: браузер может блокировать загрузку Python через file://.

## GitHub Pages

1. Создайте репозиторий `PawsOfLove` (например, публичный).
2. Загрузите содержимое папки проекта в корень репозитория, включая `.nojekyll`.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите `main`, `/ (root)`, затем Save.
5. Когда GitHub опубликует страницу, адрес появится в Settings → Pages. Обычно он выглядит как `https://USERNAME.github.io/PawsOfLove/`.

Можно вместо загрузки через интерфейс использовать команды Git, подставив собственное имя пользователя:

```powershell
git init
git add .
git commit -m "Пушистый сюрприз для мамы"
git branch -M main
git remote add origin https://github.com/USERNAME/PawsOfLove.git
git push -u origin main
```

## Файлы

- `index.html` — семь сцен и финальное поздравление. Здесь меняется основной текст и подпись.
- `style.css` — адаптивная верстка, сердечки, анимация собаки и подарка.
- `main.py` — модель Game, переходы, события, пожелания FLOWERS и письма LETTERS.
- `assets/dog/` — семь локальных WebP-иллюстраций, вырезанных из созданных визуальных концепций без текста интерфейса.
- `assets/music.mp3` — оригинальная короткая синтезированная мелодия; включается вручную в меню «Музыка».
- `tests/test_game.py` — модульные тесты игровой логики.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Серверная часть не нужна: Python выполняется в браузере через PyScript/Pyodide 2026.2.1. При первом посещении требуется доступ в интернет к CDN PyScript и его зависимостям. Загрузка может занять больше времени на медленном соединении. Иллюстрации и музыка хранятся в самом репозитории. Личные поздравления в публичном репозитории доступны всем; не добавляйте туда конфиденциальные сведения.
