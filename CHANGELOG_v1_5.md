# BorderlandContracts v1.5 — статусные маркеры контрактов на карте

**Изменены:** `src/gui/main.cpp`, `CMakeLists.txt`, `tests/GameTests.cpp`.
**Добавлен:** `src/gui/QuestMapMarkers.h`.

## Новое

- Вместо общего оранжевого счётчика у каждой локации выводятся цветные маркеры по состояниям контрактов:
  - `!` серо-синий — доступен;
  - `▶` золотой — принят;
  - `?` бирюзовый — расследован;
  - `✓` зелёный — завершён.
- Если у одной локации несколько контрактов одного статуса, маркер содержит **число**: например, `!3`.
- Наведи курсор на маркер, чтобы увидеть названия и ID всех контрактов в этой группе.
- Щелчок выбирает контракт на доске объявлений; повторный щелчок по группе с несколькими контрактами выбирает следующий.
- Выбранный контракт выделяется светлой обводкой маркера.
- Легенда отображается под картой.
- Цвета обновляются после принятия, расследования и завершения заказа, а также при загрузке другого персонажа.
- Добавлено 4 теста группировки и изменения статусов: всего 50 тестов игрового ядра.

## Установка

Заменить файлы из патча, затем выполнить:

```bash
cmake -S . -B build-qt -DCMAKE_BUILD_TYPE=Release
cmake --build build-qt -j$(nproc)
ctest --test-dir build-qt --output-on-failure
./build-qt/borderland_gui
```

База PostgreSQL и SQL-миграции **не меняются**. При работе с реальными сохранениями не используйте `--demo`.

## Ограничения

Пока карта содержит четыре заданные ранее локации (0–3). Этот патч меняет только визуализацию контрактов, не добавляет новые локации. Для новых локаций понадобится отдельный рефакторинг мировой модели, навигации, БД и карты.
